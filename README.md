# SubtitleMatcher v2.1.0

Automatic subtitle downloader and matcher for movies and TV series.

## ✨ Features

- **Smart Match** - Automatically detects movies and TV series from filenames
- **SubDL Support** - Primary subtitle source (50 free downloads/day)
- **OpenSubtitles Support** - Fallback subtitle source
- **TMDB Integration** - Fetches movie posters, ratings, and metadata
- **Multi-language Support** - English, Finnish, Swedish, Norwegian, Danish, and more
- **Progress Tracking** - Real-time progress bar with percentage
- **Clean UI** - Modern dark theme with movie info panel
